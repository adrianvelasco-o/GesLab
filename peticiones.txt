POST   /practicas                      → Crear nueva práctica
GET    /practicas                      → Listar todas las prácticas
GET    /practicas/:id                  → Obtener una práctica por ID
PUT    /practicas/:id                  → Actualizar una práctica
PATCH  /practicas/:id/enviar-revision  → Enviar práctica a revisión

# Instrumentos de evaluación
POST   /practicas/:id/instrumentos     → Crear instrumento de evaluación
GET    /practicas/:id/instrumentos     → Listar instrumentos
DELETE /practicas/:id/instrumentos/:instrumentoId → Eliminar instrumento

# Revisiones docentes
POST   /practicas/:id/revisiones       → Registrar revisión docente
GET    /practicas/:id/revisiones       → Listar revisiones

POST   /documentos                     → Subir documento (PDF multipart)
GET    /documentos/practica/:id        → Listar documentos de una práctica

GET    /reservas/laboratorios          → Listar laboratorios disponibles
POST   /reservas                       → Crear nueva reserva
GET    /reservas                       → Listar reservas
GET    /reservas/:id                   → Obtener reserva por ID
PATCH  /reservas/:id/aprobar           → Aprobar reserva
PATCH  /reservas/:id/rechazar          → Rechazar reserva
